# Sales-Performance-Customer-Analysis


TOOL TO USE:
Excel

STEP 1: DATA UNDERSTANDING
- Understand each column
- Identify data types
- Check date range and total records

STEP 2: DATA CLEANING (DO IN ALL TOOLS)
- Check for missing values
- Remove duplicates
- Ensure correct data types
- Create Month and Year from Order_Date

STEP 3: KPIs TO CREATE
- Total Sales
- Total Orders
- Average Order Value
- Total Quantity Sold
- Total Customers
- Average Discount

STEP 4: ANALYSIS QUESTIONS
- Which region has highest sales?
- Which category and product sells most?
- Monthly sales trend
- Top 10 customers by sales
- Impact of discount on sales

STEP 5: DASHBOARDS TO BUILD
Dashboard 1: Sales Overview
- KPI cards (Total Sales, Orders, Customers)
- Sales by Region (Bar/Map)
- Sales by Category (Donut/Pie)

Dashboard 2: Time Analysis
- Monthly Sales Trend (Line Chart)
- Month vs Category sales

Dashboard 3: Product & Customer Analysis
- Top Products by Sales
- Top Customers by Revenue

STEP 6: TOOL-SPECIFIC TASKS
EXCEL:
- Pivot Tables
- Pivot Charts
- Slicers for Region and Category
